Scenario D · Temporary broker failure

Kafka fails twice. The relay records each attempt and publishes on the third run.

OverviewABCDEEspañol

What to look for

  • Each failure leaves the event in FAILED and increments attempts.
  • FAILED is still pending, so the next run retries it.
  • On the third run Kafka accepts it: FAILED → FAILED → SENT, and the consumer creates the payment.
